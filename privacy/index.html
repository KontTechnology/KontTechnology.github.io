Privacy Policy

Service: Kont Yayin — the internal publishing tool of the Kont Technology YouTube channel (@konttechnology)
Operator: Turgut Kont (individual developer, Istanbul, Türkiye) · Contact: konttechnology@gmail.com
Last updated: 6 November 2026

1. Summary

Kont Yayin is a private command-line tool that the channel owner runs on his own computer to publish his own videos to his own YouTube channel. It is not offered to the public, has no other users, no website login, no cookies and no server. It does not collect, store or share data about any other person or channel.

2. Use of YouTube API Services

Kont Yayin uses the YouTube API Services. By using this tool you agree to be bound by the YouTube Terms of Service. Information handled through the YouTube API Services is also subject to the Google Privacy Policy.

The tool uses the YouTube Data API only to:

  • upload the channel's own original videos (as private, with a scheduled publish time);
  • upload the channel's own subtitle (SRT) files;
  • edit the titles and descriptions of the channel's own playlists and add the channel's own videos to them;
  • post a question comment under the channel's own videos and read the channel's own video and playlist details.

3. What data is accessed and stored

  • OAuth 2.0 credentials: the channel owner signs in with his Google account. The resulting access/refresh token is stored only on the owner's computer in a file readable only by that user. It is never uploaded, shared or sent anywhere except to Google.
  • Video data: titles, descriptions, tags, subtitles and video files come from the owner's local production folders. The only YouTube data kept locally is the list of uploaded video IDs and their scheduled dates.
  • No third-party data: the tool does not read, collect or store data of other YouTube users or channels, and it contains no analytics, advertising or tracking.

4. Sharing

No data obtained through the YouTube API Services is sold, shared with or disclosed to any third party.

5. Retention, deletion and revoking access

  • Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
  • When access is revoked, or on request by e-mail, the stored token and the local list of video IDs are deleted within 7 days. Stored YouTube API data is not kept longer than 30 days without being refreshed.
